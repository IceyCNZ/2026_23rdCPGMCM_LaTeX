\section{模型的建立与求解}
\label{sec:model}

\subsection{问题一的模型建立}

\subsubsection{变量定义与数据处理}
根据题意确定决策变量 $\bm{x}=(x_1,x_2,\ldots,x_n)^{\mathsf T}$，并对输入数据进行统一处理。数据预处理的规则应在建模前确定，以保证不同方法的比较使用相同的数据基础。

文献引用使用方括号编号，例如书籍中的相关方法可写为文献~\cite[第10--20页]{demo-book}。此处文献条目为明确标记的占位示例，正式使用时必须替换为真实来源与实际引用页码。

\subsubsection{目标函数与约束条件}
为演示公式排版，考虑带总量约束的加权平方偏差模型：
\begin{equation}
  \begin{aligned}
    \min_{\bm{x}}\quad
      &F(\bm{x})=\sum_{i=1}^{n}w_i(x_i-a_i)^2,\\
    \text{s.t.}\quad
      &\sum_{i=1}^{n}x_i\le b,\\
      &x_i\ge 0,\qquad i=1,2,\ldots,n.
  \end{aligned}
  \label{eq:model}
\end{equation}
\Cref{eq:model} 中，$w_i$ 用于描述不同偏差项的相对重要性。正式建模时应解释目标函数的实际意义，以及各项约束与原问题之间的对应关系。

\subsubsection{模型性质}
当各权重均为正时，目标函数的 Hessian 矩阵为
\begin{equation}
  \nabla^2F(\bm{x})
  =2\operatorname{diag}(w_1,w_2,\ldots,w_n).
  \label{eq:hessian}
\end{equation}
由\Cref{eq:hessian} 可知目标函数严格凸。在约束集合非空的条件下，结合可行域的结构，可以进一步分析最优解的存在性与唯一性。类似论证可以结合期刊文献中的方法展开~\cite{demo-article}。

\begin{enumerate}

\section{模型检验与灵敏度分析}

\subsection{模型检验}
将模型输出与已知结果、保留数据或基准方法进行比较，检查结果是否满足实际约束。若采用误差指标，应写清定义、计算范围和比较方式，避免仅凭图形相似就认定模型有效。

以观测值 $y_i$ 和预测值 $\hat y_i$ 为例，均方根误差可写为
\begin{equation}
  \operatorname{RMSE}
  =\sqrt{\frac{1}{m}\sum_{i=1}^{m}(y_i-\hat y_i)^2}.
\end{equation}
误差分析应结合问题的量纲与实际需求解释，必要时分别讨论总体误差和局部误差。

\subsection{灵敏度分析}
选择对结论可能有显著影响的参数，在合理区间内逐一改变或联合扰动，观察目标函数、决策变量及约束满足情况的变化。

\subsubsection{参数扰动方案}
说明扰动范围、采样方式以及其他参数是否保持不变。若参数由数据估计得到，扰动幅度应尽量与估计误差或实际变化范围相一致。

\subsubsection{稳健性讨论}
结合扰动结果讨论模型结论是否稳定，指出敏感参数以及需要提高测量精度的环节。出现不稳定现象时，应分析其来自数据、模型结构还是求解算法。

\section{模型评价与推广}

\subsection{模型的优点}
结合建模过程与检验结果说明模型的优势，例如变量含义清晰、约束表达完整、求解效率适用或结论具有可解释性。每项优点都应有相应依据。

\subsection{模型的局限}
说明假设简化、数据质量、参数估计以及算法近似带来的限制。局限应对应实际存在的问题，并尽量给出其可能影响结论的方向。

\subsection{模型的推广}
说明模型可迁移到哪些相近问题、迁移时需要调整哪些条件，以及哪些结论不能直接推广。推广部分应与已有模型保持联系，避免脱离已完成的分析。

\subsection{程序示例}
下列 Python 代码仅用于演示代码排版与目标函数计算，不是完整求解器。实际提交时应替换为能够复现论文结果的程序。

% 较长程序可使用 \lstinputlisting[language=Python]{程序文件路径}。
\begin{lstlisting}[language=Python]
def objective(x, targets, weights):
    if not (len(x) == len(targets) == len(weights)):
        raise ValueError("Input lengths must match.")
    if any(weight <= 0 for weight in weights):
        raise ValueError("Weights must be positive.")
    return sum(
        weight * (value - target) ** 2
        for value, target, weight in zip(x, targets, weights)
    )


value = objective([1.0, 2.0], [1.5, 2.5], [1.0, 2.0])
print(value)
\end{lstlisting}
